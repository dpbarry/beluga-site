Keybindings

# C-c C-l filename.bel  
  Load
   
# C-c C-x command  
  Execute Command
   
# C-c C-c  
  Compile
   
# C-c C-s int id  
  Split, where id specifies the variable
   
# C-c C-i int  
  Variable introduction
   
# C-c C-t  
  Type-check at cursor location

The integers are base-0 indexes denoting the relative position of the hole in question, ie: 0 refers to the first hole, 1 refers to the second hole, etc...
