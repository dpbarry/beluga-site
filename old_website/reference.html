Beluga Quick Reference




Syntax

This guide uses the following notation, presented by example:
tokenname ::= first-alternative
| second-alternative      
| # Third alternative, a single bold literal character
| digit+ Fourth alternative: one or more digits
| (A | ... | Z)(symchar)* Fifth alternative: any uppercase letter followed by zero or more symchars
nonterminal-symbol ::= let sym [: cmp-typ] = cmp-exp-syn ;        Let-expression with optional type annotation (indicated by "[ ]")

Lexical

  • Reserved characters: % , . : ; ( ) [ ] { } \ "
digit ::= 1 | 2 | 3 | 4 | 5 | ... | 9
number ::= (digit)+
sym ::= startchar(symchar)*
upsym ::= (A | ... | Z)(symchar)*
startchar ::= A | ... | Z | a | ... | z
| ! | $ | & | ' | * | + | - | / | : | = | ? | @
| (any non-ASCII UTF-8 character)
symchar ::= A | ... | Z | a | ... | z
| ! | $ | & | ' | * | + | - | / | : | = | ? | @
| digit
| #
| (any non-ASCII UTF-8 character)

Reserved words:      |    !    =    +    *    <    >    ->    <-    =>    FN    block    case    fn    in    let    mlam    of    rec    schema    some    type    %name    %not

Reserved but unused:    box    coercion    id

The characters < and > are also permitted in identifiers; however: no letter can follow < or precede a >, and a symbol containing either can only contain:

      ! $ & ' * + - / : = : ? @ ^ ` | ~ #

(In <g, x. U .. x>, intended to form part of a meta-variable application, we thus interpret <g as < g, not as a single identifier <g.)

Notes. The rules for symbols (identifiers) are more permissive than ML, but less permissive than Twelf, Scheme, etc. Achieving the permissiveness of Twelf seems very hard in Beluga, due to the (relatively) rich syntax of Beluga's computation layer.

Grammar

program ::= declaration* A program is a sequence of zero or more declarations
declaration ::= sym : kind . Declare sym to have kind 'kind', e.g. list : nat -> type.
| sym : type . Declare sym to have type 'type', e.g. cons : element -> list N -> list (succ N).
| %name sym upsym [sym] . Set names for printing elements of the just-declared type, e.g. nat : type. %name nat N n.
| %notFor testing only
| schema sym = schema-elem (+ schema-elem)* ; Declare context schema of declarations matching any listed schema-elem
| let sym [: cmp-typ] = cmp-exp-syn ;
| rec cmp-rec (and cmp-rec)* ; Declare (mutually recursive) computation-level function(s)
kind ::= { sym : type } kind
| kind -> kind
| kind <- kind
| type
type ::= { sym : type } type
| type -> type
| type <- type
| lf-typ
lf-typ ::= { sym : lf-typ } lf-typ
| lf-typ -> lf-typ
| lf-typ <- lf-typ
| ( lf-typ )
| sym lf-term*
lf-term ::= \ sym . lf-term
| sym lf-term*
| _
| ( lf-term )
schema-elem ::=[some [ sym : lf-typ (, sym : lf-typ)* ] ] lf-typ-rec
lf-typ-rec-opt::=lf-typ-rec
| _
lf-typ-rec::=[ block sym : lf-typ (, sym : lf-typ)* . ] lf-typ
lf-hat-elem ::= sym
clf-ctyp-decl ::={ # sym :: clf-typ-sigma [ clf-dctx ] }
| { upsym :: clf-typ [ clf-dctx ] }
clf-term ::= \ sym . clf-term-app
| upsym
| ( upsym clf-sub )
| clf-head
| _
| ( clf-term-app )
| < clf-term-app (, clf-term-app)* >
clf-typ ::={ sym : clf-typ } clf-typ
| ( clf-typ )
| clf-typ -> clf-typ
| sym clf-term*
clf-typ-sigma ::=block clf-typ-rec-elem (, clf-typ-rec-elem) . clf-typ
| ( clf-typ-sigma )
| sym clf-term*
clf-typ-rec-elem ::=sym : clf-typ
| upsym : lf-typ
clf-term-x ::= clf-term
| upsym [clf-sub]
clf-term-app ::= clf-head clf-term*
| clf-term-x
clf-head ::= # sym [. number] clf-sub
| sym [. number]
clf-sub ::= ..
| clf-sub clf-head
| clf-sub clf-term
| clf-head
| clf-term
clf-dctx ::= (empty string)
| sym
| sym : clf-typ
| clf-dctx , sym : clf-typ
cmp-typ ::= { sym : ( sym ) * } cmp-typ
| cmp-typ -> cmp-typ
| clf-ctyp-decl cmp-typ
| cmp-typ * cmp-typ
| clf-typ [ clf-dctx ]
| ( cmp-typ )
cmp-rec ::= sym : cmp-typ = cmp-exp-chk
cmp-exp-chk ::= fn sym => cmp-exp-chk Computation-level abstraction
| FN sym => cmp-exp-chk Context variable abstraction
| mlam upsym => cmp-exp-chk Meta-variable abstraction
| case cmp-exp-syn of [|] cmp-branch (| cmp-branch)* Case expression
| let ( sym , sym ) = cmp-exp-syn in cmp-exp-chk LetPair
| let clf-ctyp-decl* [ clf-dctx ] clf-term-app [: clf-typ [ clf-dctx ]]
= cmp-exp-syn in cmp-exp-chk Let
| [ lf-hat-elem (, lf-hat-elem)* ] clf-term-app Boxed data
| ( cmp-exp-chk )
| ( cmp-exp-chk , cmp-exp-chk )
| cmp-exp-syn
cmp-exp-syn ::= cmp-exp-syn [ clf-dctx ] Context application
| cmp-exp-syn < [lf-hat-elem (, lf-hat-elem)*] . clf-term-app > Meta-variable application
| cmp-exp-syn cmp-exp-chk Computation-level application
| sym Variable
| [ clf-dctx ] clf-term-app BoxVal
cmp-branch ::= clf-ctyp-decl* [ clf-dctx ] clf-term-app [: clf-typ [ clf-dctx ] => cmp-exp-chk
