Keybindings

# C-c C-x command  
  Execute shell command
   
# C-c C-c  
  Compile
   
# C-c C-l filename.bel  
  Load (necessary before the next commands)
   
# C-c C-s num id  
  Split on variable id at hole num
   
# C-c C-i num  
  Introduce variable num
   
# C-c C-t  
  Get type of the term under the cursor

Note that the hole numbers num count the holes in order of occurrence, starting at 0.
