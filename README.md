# Beluga website

Source for the Beluga homepage https://www.cs.mcgill.ca/~complogic/beluga/

## Layout

| Path | What it is |
| --- | --- |
| `index.html`, `style.css`, `site.js` | The current site |
| `bel-icon.svg`, `MCGILL.svg`, `fonts/` | Assets for the current site |
| `legacy/` | The old homepage |
| `tutorial/`, `examples/`, `userguide2/`, `papers/`, `*.pdf`, `*.tar.gz` | Long-standing material |


## Deploying

Clone this repo, make edits, push to main, and then run these commands on our server:

```sh
cd ~/public_html/beluga
git pull
```
